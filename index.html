How to enable Google synchronization
  1. Host this HTML file on an HTTPS website (or localhost for development). Google authorization does not work from a downloaded file opened as file://.
  2. In Google Cloud Console, create a project, enable the Google Calendar API, configure the OAuth consent screen, and create an OAuth client ID of type Web application.
  3. Add your website's exact origin to Authorized JavaScript origins. Add your Google account as a test user if the app is in Testing.
  4. Paste the client ID above, save it, and click Connect Google. Grant Calendar permissions when Google asks.

Google events are fetched for November 2026 through December 2027. Refresh to retrieve updates made on other devices. Google authorization tokens are kept in memory, not saved to your browser.
